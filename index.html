🔥 Đồng bộ Cloud — Firebase

Hướng dẫn tạo Firebase miễn phí (5 phút):
1. Vào console.firebase.google.com → tạo Project mới
2. Vào Build → Realtime Database → Create database → chọn Test mode
3. Vào Project Settings ⚙️ → General → cuộn xuống "Your apps" → bấm </> Web
4. Copy các giá trị databaseURL và apiKey dán vào đây
⚠️ Phải có đuôi .firebaseio.com
